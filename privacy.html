Privacy Policy

Last updated: 25 November 2026

evveltimes-upload is a personal tool for the owner of the Evvel Times YouTube channel. This policy explains what it does with Google user data.

Data accessed

When the owner signs in, the app requests permission to upload videos and manage the channel's videos and comments (YouTube Data API scopes youtube.upload and youtube.force-ssl). It reads basic channel information (channel name, ID, subscriber count) and the status of videos it uploads.

How data is used and stored

Data is used only to upload, schedule and update the owner's own videos. The sign-in token is stored in a file on the owner's own computer. The app has no server and no database. It does not collect, sell, share or transfer Google user data to anyone, and it uses no data for advertising.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services and is subject to the YouTube Terms of Service and the Google Privacy Policy.
